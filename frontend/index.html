SOURCE CUSTODY / 04

Bring your own catalogue.

A source custodian imports feature-complete CSV records and attaches five station traces. Distinct reviewer credentials are required for blind verdicts.

Read only

Import CSV

Required fields

event_id, n_pha_total, n_sta, moveout_rms, az_gap, sec_az_gap, dist_nearest_sta_km, mag

Optional columns: time, lat, lon, dep. Angles use degrees; nearest-station distance uses kilometres. Unknown-region and out-of-support scores abstain.

Review gate

Open an imported detection to attach a JSON waveform file with exactly five station traces, a sample rate, and a source reference. The service checks shape, not trace authenticity. Reviewers use separate tokens and cannot claim an arbitrary reviewer ID. The reference archive has no continuous waveforms.
