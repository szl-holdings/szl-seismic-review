OPERATOR / 04

Bring your own catalogue.

Import feature-complete CSV records for a research queue. Fresh blind reviews require five operator-supplied station traces per event and an authorized operator.

Read only

Import CSV

Required fields

event_id, n_pha_total, n_sta, moveout_rms, az_gap, sec_az_gap, dist_nearest_sta_km, mag

Optional columns: time, lat, lon, dep. Angles use degrees; nearest-station distance uses kilometres. Unknown-region and out-of-support scores abstain.

Review gate

Five blinded station traces, sample rate, and a waveform source reference must be attached through the API before a reviewer can choose confirmed, unresolved or rejected. The service checks trace shape, not authenticity. The source archive has no continuous waveforms.
